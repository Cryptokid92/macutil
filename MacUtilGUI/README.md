# MacUtil GUI

Avalonia UI for MacUtil. The window is opaque `#1C1C1E`. The menu bar name is MacUtil.

Tweaks binds `config/tweaks.json` checkboxes to `ActionEngine`. Standard and Minimal select preset ids. Import and Export read and write a JSON array of ids. Install binds `config/applications.json` checkboxes to `BrewClient`. Search filters the Install list.

Run from the repo root:

```bash
dotnet run --project MacUtilGUI/MacUtilGUI.fsproj
```
